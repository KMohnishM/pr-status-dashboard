# PR Status Dashboard

PR Status Dashboard is a lightweight workspace for tracking pull request status in one place. The repository is currently a starter scaffold, so this README sets the project direction and outlines the intended shape of the app.

## What It Will Do

- Surface open pull requests and their current checks.
- Highlight blocked, failing, and ready-to-merge work.
- Make it easy to scan review progress without switching tabs.

## Suggested Scope

- A compact dashboard view for PR health.
- Status summaries for checks, reviews, and merge readiness.
- Filters for repository, author, and state.
